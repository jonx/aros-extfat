# Hosted media qualification

The preserved exFAT guide references Macaros's host-media tests. Those depend
on its hosted AROS runtime, file-backed devices and control harness; they are
not part of this standalone host test runner.

See [the exFAT handover](../exfat/HANDOVER.md) for retained qualification details
and [integration](../../../integration/README.md) for the runtime boundary.
